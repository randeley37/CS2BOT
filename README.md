## CS2BOT
Best bot for you cs2 community, lots of features

Main Features

# ⚙️ Installation
1. Buy dsicord bot with randeley on discord.gg/streettuga
2. Download the latest verison
3. Unzip
4. Configure token and stuff in src/Configs/config.js
5. Start with "node ."

# 🛠️ Features
Advanced Multiple Servers Status
Ticket System
Temporary Voice Channels
Welcome Messages
Log Messages
Clear Messages
Twitch/Youtube Streaming warnings
Sticky Message
Temporary Support Voice Channel

# 📋 Requirements
Node JS V22 (Maybe other versions work i didnt tested it)
